## Description test cases for Habr UI tests

### Отображение кнопки «Войти» на главной странице (visibleEnterButton)
1. Открыть `https://www.habr.com/`
2. Проверить, что кнопка «Войти» отображается

### Кликабельность кнопки «Войти» (enterButtonShouldBeClickable)
1. Открыть `https://www.habr.com/`
2. Проверить, что кнопка «Войти» кликабельна

### Переход на форму авторизации по клику «Войти» (openLoginForm)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Проверить, что форма авторизации отображается

### Кликабельность ссылки «Забыли пароль» (clickableRemindPasswordButton)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Проверить, что ссылка «Забыли пароль» кликабельна

### Переход на форму восстановления пароля (goRecoveryPassword)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Нажать «Забыли пароль»
4. Проверить, что отображается форма восстановления пароля

### Отображение кнопки «Войти с помощью GitHub» (checkGitSocialButton)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Проверить, что отображается кнопка «Войти с помощью GitHub»

### Вход без заполнения логина и пароля (loginWithoutData)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Отправить форму без заполнения данных
4. Проверить, что email помечен как некорректный

### Вход с невалидными логином и паролем (loginWithInvalidCredentials)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Ввести невалидный email и пароль
4. Нажать кнопку «Войти»
5. Проверить, что переход в аккаунт не выполнен

### Отправка пустой формы восстановления пароля (sendEmptyRecoveryPassword)
1. Открыть `https://www.habr.com/`
2. Нажать кнопку «Войти»
3. Перейти к восстановлению пароля
4. Отправить форму без ввода email
5. Проверить, что поле email помечено как некорректное
